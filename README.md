九号出行的 LSPosed 模块：把手机上的任意应用投到车辆仪表，并在仪表画面上叠加手机状态、音乐、胎压、电压、速度、功率、通知等控件，把手机导航的转向信息送到仪表。

## 能做什么

- **画面提供方式**：投屏（系统录屏，Android 11+）、虚拟显示器（Root 或 Shizuku / Sui，Android 14+）、绘制（模块自己画速度表和最多三项信息，Android 11+）三选一。
- **应用投屏**：在车辆页的“仪表投屏导航”卡片一键开始投屏，把指定应用放到独立虚拟屏上运行，或用系统录屏分享单个应用 / 整个屏幕，画面走九号自己的编码和发送链路。可以先在手机上设好导航再投屏，副屏上自动重新规划到同一目的地。
- **仪表控件**（虚拟显示器方式）：手机电量与信号、音乐、胎压、电压、速度、功率、通知、音量，可排序、可设显示条件；胎压和电压等数据用九号自身的蓝牙读取接口补读。
- **手机导航上仪表**：高德导航时，转向箭头、剩余距离时间、当前 / 下一路名实时写到仪表的巡航画面（腾讯、百度接入中）。
- **手机预览与输入**：虚拟显示器可以先于投屏启动并一直保留，在手机上预览、触摸、返回、输入文字；投屏随时接上或断开。
- **编码与统计**：可覆盖编码码率和帧率；查看采集、编码、发送、丢帧和仪表反馈的实时统计。
- **更新提示**：从 GitHub Releases 检查新版本，有更新时提示并可直接打开 Release 页面，“关于”里可手动检查；不自动下载。
- **隐藏功能**：显示被车辆功能位隐藏的双向转把选项、仪表按键卡片和原版巡航入口。
- **BMS 管理**：支持 DL / ANT / JBD / JK / 彦阳 五种保护板协议，在 BMS 管理里选定；DL 本地完成 secp256k1 握手，其余四种由模块直接读取，仪表上多一张最多三行、字段可选可排序的 BMS 卡片；数据读取设置里可把电压 / 功率来源切到 BMS。
- **大灯控制**：绑定 TX 灯控、蓝牙电调（摩灯客大灯电调）、摩灯客卷帘控制器或 SG 灯控后，仪表上多一张大灯卡片；能定位的按百分比一档一档走，SG 灯控按设定的点动时长向上或向下运行；没放音乐时音量加减键直接调灯，音量本身不变。
- **触摸屏管理**：把 USB 或蓝牙外接触摸屏绑定到虚拟屏，投屏期间面板上的触摸直接落到副屏应用，手机自己的屏幕不受影响；四个安装方向可选。
- **模块本体**：首次打开进入引导：选画面提供方式、授权、检查权限、连接大灯和 BMS；之后是权限检测页，列出每项授权的状态和用途，未授权的点一下即可申请；底部一键强制退出九号出行。

## 适配范围

| 项目 | 范围 |
| --- | --- |
| 九号出行 | 支持 6.10.10（610104038）、6.10.11（610114116）和 6.10.12（610124146）三个版本；6.10.12 业务 dex 由网易加固包裹，类钩子目标运行时核对；其他版本照常工作，设置顶部红字提示未测试，钩子目标由运行时自检核对 |
| Android | 11–16（API 30–36）；虚拟显示器仅 Android 14+ |
| LSPosed | libxposed API 101 或后续兼容 API |
| 作用域 | 九号出行；导航上仪表另需高德地图、腾讯地图、百度地图 |
| 授权 | 虚拟显示器需 Root 或 Shizuku / Sui（API 13+）；投屏和绘制不需要 |

已在 M5P（车型 14103，仪表 848×480，Wi-Fi Direct H.264）实测；240×320 竖向半屏仪表（蓝牙 MPEG2）按配置自动适配整帧，待实测；其他车型、手机和系统可能不同。

## 安装

1. 安装 `NinebotEnhance-1.1.15.apk`，在 LSPosed 启用模块并勾选作用域。
2. 强制停止并重新打开九号出行，连接车辆后进入车辆信息页，“仪表投屏导航”卡片底部一行是虚拟显示器图标、“全屏投屏”和“设置”，点“设置”；没连车时点页面底部“拥有爱车第 x 天”一行也能进设置，家庭账号下那一行是车辆名，长按即可进入。
3. 在设置里完成授权方式，选择启动应用后保存；左侧的虚拟显示器图标随时可用，“全屏投屏”也一直可点，点击后直接调用九号原巡航入口，是否开机由九号自己的巡航逻辑检查。

详细的每项功能说明、授权方式、统计与日志见 [使用手册](docs/manual.md)，实现细节见 [架构与统计](docs/architecture.md)，预览输入见 [预览与输入](docs/preview-input.md)。

## 构建

需要 JDK 17+、Python 3.11+、Android SDK Platform 36.1 和 Build Tools 37.0.0。

```sh
./gradlew :app:assembleDebug
python scripts/build.py --sdk "$ANDROID_HOME" --jdk "$JAVA_HOME" --allow-other-signer
```

前者产出调试 APK，后者运行主机测试并打包签名到 `dist/`；发布流程见 [发布说明](docs/release.md)。

## 说明

- 模块只通过九号自身接口读取车辆数据，对车辆的写入只有导航显示数据（仪表指令 113）和仪表昼夜主题，不改任何车辆设置。
- 大灯是另一台设备，走模块自己申请的蓝牙权限和自己的连接，与车辆链路无关。大灯和 BMS 的链路只在九号界面可见或投屏期间保持，九号退到后台即断开，模块不在后台保持任何连接。
- 导航 App 里只有观察钩子，不改变它们的行为。
